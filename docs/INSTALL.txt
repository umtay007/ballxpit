BALLxPIT Online Co-op 0.1.1
===========================
Play sparrow's "BALLxPIT: Local Coop" with a friend who is anywhere. Only you (the host) need the
game and the mods. Your friend opens a link in their web browser, sees your screen, hears the game
and controls Player 2 with keyboard and mouse or a controller.

Windows only.


INSTALL (host only)
-------------------
1. Close the game.
2. BepInEx 6, the mod loader (skip if your game already runs BepInEx 6; BepInEx 5 does not work
   with BALL x PIT). Download
       https://builds.bepinex.dev/projects/bepinex_be/788/BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.788%2B5b766a3.zip
   and extract everything in it into the BALL x PIT game folder, the one with BALLxPIT.exe (for
   example E:\SteamLibrary\steamapps\common\BALLxPIT).
   Careful: Windows' "Extract All" suggests a new folder named after the zip. Remove that part of
   the path. Afterwards these must sit right next to BALLxPIT.exe:
       winhttp.dll   doorstop_config.ini   dotnet\   BepInEx\
3. Extract this zip into the same game folder, again without an extra folder, and allow it to
   overwrite files. It adds:
       BepInEx\plugins\BALLxPITLocalCoop.dll
           sparrow's Local Coop 0.1.0 plus two small input hooks. It replaces the original and plays
           exactly the same when nobody is online.
       BepInEx\plugins\BALLxPITOnlineCoop\BALLxPITOnlineCoop.dll
           The online part.
       BepInEx\config\BepInEx.cfg
           Turns off a BepInEx feature that doesn't work in Unity 6 games like this one.
   If an old BALLxPITLocalCoop.dll lives somewhere else under BepInEx\plugins, delete it. (If you
   forget, BepInEx still picks the new one because its version is higher.)
(If you have BALLxPITOnlineCoop-with-BepInEx.zip, it already contains step 2: just extract it.)

4. Start the game. The FIRST start takes a few minutes: a black BepInEx window with scrolling text
   opens and BepInEx prepares the game (it downloads some Unity files, so stay online). Don't close
   that window; closing it closes the game. Later starts are quick.
5. In the main menu an "Online Co-op (F8)" button appears in the top-right corner, and when you
   start a run a second player (Local Coop's P2) stands next to you. If not, see
   "If something's off" below.


HOST A GAME
-----------
1. Press F8 (or click the "Online Co-op (F8)" button) and click "Host an online game".
2. Wait a few seconds for a line like
       Internet link: https://some-random-words.trycloudflare.com/#K7QM2P  (click to copy)
   The first time, the mod downloads cloudflared.exe (Cloudflare's free tunnel program, about
   40 MB) into BepInEx/plugins/BALLxPITOnlineCoop. Click the line to copy the link.
3. Send the link to your friend (Discord, text, anything). They open it in Chrome, Edge or
   Firefox, type a name and click "Join as Player 2". The code after # is the password, so only
   people you send the link to can get in.
4. Start a run. Your friend now controls P2. You still do the menus, level-up picks and pausing.

Other links the panel can show:
  Direct link       http://your-ip:47777/...  Offered when your router accepts UPnP. A little less
                    lag than the internet link. Controllers may only work on the https link.
  Same Wi-Fi link   For someone in your house.
Windows may ask whether BALLxPIT may accept connections: allow it for the direct and Wi-Fi links.
The internet link works either way.

More people can open the link while P2 is taken; they watch, and get a "Play as P2" button when
the spot frees up. Use "Kick P2", "New code" and "Stop hosting" in the F8 panel.


YOUR FRIEND'S CONTROLS
----------------------
  Move                WASD or arrow keys, or the left stick
  Aim                 point with the mouse, the right stick, or hold J / L to turn
  Shoot               hold the left mouse button or Space, or RT / A
  Auto-shoot on/off   E or right-click, or Y
  Full screen         F        Sound on/off   M        Help   H


IF SOMETHING'S OFF
------------------
- No black BepInEx window on start, and no BepInEx\LogOutput.log afterwards: BepInEx isn't
  running. winhttp.dll and doorstop_config.ini must be right next to BALLxPIT.exe, not in a
  subfolder.
- No "Online Co-op (F8)" button in the main menu, and no second player in runs: the mods aren't
  loading. Check the two DLL paths above and that there's no extra BepInEx folder one level down,
  such as BALLxPIT\BALLxPITOnlineCoop\BepInEx. BepInEx\LogOutput.log says what went wrong.
- The button is there but F8 does nothing: some keyboards need Fn+F8, and other programs can take
  F8. Click the button instead, or pick another key with PanelKey in the config.
- "Still connecting to Cloudflare": a firewall or antivirus is blocking cloudflared.exe. Allow it,
  or use the direct link.
- The panel says your Local Coop DLL is the original: the old BALLxPITLocalCoop.dll is still being
  loaded. Delete it and keep the one from this zip.
- Choppy or blurry picture: your upload is the limit. The mod already lowers quality by itself. In
  BepInEx/config/BALLxPITOnlineCoop.cfg you can set MaxWidth = 640 or MaxFps = 20.
- Picture upside down for your friend: they press H and tick "Flip it".
- No game sound for your friend: set StreamAudio = false if it causes any trouble for you.
- Game stutters for you while hosting: lower MaxFps in the config.
Everything the mod does is logged in BepInEx/LogOutput.log.

Settings live in BepInEx/config/BALLxPITOnlineCoop.cfg (created on first start).
